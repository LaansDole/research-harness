research-harness — live TUI captures

Two unedited terminal recordings of research-harness driving oh-my-pi: real agent turns, real output, no staged replay.

1600x1000 · full length · open-access APIs only

1 · End-to-end /litreview run

scholar → screener → synthesizer, over a local PDF corpus (offline). The run screens candidates against explicit criteria, writes the cited review, and files the includes into the paper graph.

98 s · 1600x1000 · recorded with vhs. Ends on the requested stats line GRAPH -> 4 papers / 6 edges.

  • Recorded before research mode shipped: /litreview and the paper graph are unchanged since.
  • Not shown here: the mode's command set, review.db, and the PRISMA-ScR diagram.

2 · The librarian agent grows the paper graph

Corpus scan, add/link with metadata, OpenAlex auto-edges, a connection query, and the offline HTML export — all inside the TUI.

90 s · 1600x1000 · ends on the graph stats.

3 · The exported paper graph

One self-contained HTML file: vanilla-JS force-directed canvas, node size by degree, edge colours by type, search, drag/zoom/pan, click for metadata. No external assets — it works from file://.

Why these live here: GitHub refuses to render repository blobs larger than about 1 MB in its file view and serves repository blobs as application/octet-stream, so a committed MP4 cannot be watched in place. GitHub Pages serves them as real video/mp4, so they play here at full quality.
